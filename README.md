## 🌟 Tentang MUYANG

**MUYANG (Murah Kenyang)** adalah platform digital terpadu yang membantu mahasiswa baru dan anak kos di sekitar Universitas Jember (UNEJ) menemukan makanan enak, murah, dan porsi mengenyangkan sesuai uang saku harian mereka. Platform ini juga menjadi sarana digital marketing terjangkau bagi para pelaku UMKM kuliner lokal untuk menjangkau puluhan ribu mahasiswa kampus.

---

## 🚀 Fitur Unggulan Web Platform

1. **Filter Budget Nominal (Product-Solution Fit #1)**
   - Slider filter harga uang saku mahasiswa (Rp 5.000 s/d Rp 25.000+).
   - Filter cepat kategori: Warteg & Prasmanan, Ayam & Bebek, Mie & Bakso, Nasi & Lauk, serta Hidden Gem dalam gang kos.
   - Filter per area sekitar UNEJ (Jl. Jawa, Jl. Kalimantan, Jl. Mastrip, Jl. Danau Toba, Jl. Riau, Jl. Karimata).

2. **Katalog & Profil Tempat Makan Terpadu (Product-Solution Fit #2)**
   - Daftar menu aktual dengan harga terverifikasi.
   - Jam operasional, alamat lengkap, dan fasilitas mahasiswa (WiFi, colokan, nasi ambil sendiri, free es teh).
   - "Kenyang Score" berbasis ulasan porsi riil anak kos.

3. **Radar & Peta Kuliner Kampus UNEJ (Product-Solution Fit #3)**
   - Peta visual interaktif yang memetakan posisi warung makan di sekitar jalan utama kampus UNEJ dan Fasilkom.
   - Pin interaktif dengan label harga menu termurah dan status featured listing.

4. **Kalkulator Kenyang Seharian (Meal Budget Planner)**
   - Masukkan nominal uang saku makan harian (misal Rp 20.000 atau Rp 25.000).
   - Algoritma otomatis menyusun menu 3x makan (Sarapan, Makan Siang, Makan Malam) yang pas dengan budget dan memaksimalkan porsi kenyang.

5. **Pitch Deck & Business Architecture Hub (Slide 1 - 8)**
   - **Slide 1:** Profil Tim Pengembang Kelompok 6 UNEJ.
   - **Slide 2:** Background Problem (Kondisi, Masalah, Dampak Mahasiswa vs UMKM).
   - **Slide 3:** Business Model Canvas (9 blok interaktif).
   - **Slide 4:** Value Proposition Canvas (Customer Profile vs Value Map).
   - **Slide 5:** Product-Solution Fit Matrix (5 masalah vs solusi vs fitur).
   - **Slide 6-7:** Market Size TAM (Rp 120 Juta), SAM (Rp 48 Juta), SOM (Rp 12 Juta), Basis Pengguna (38.995 Mahasiswa UNEJ) + **Simulator Finansial Interaktif**.
   - **Slide 8:** Competitor Analysis Matrix (Muyang vs Google Maps vs Ojol vs Medsos vs Rekomendasi Teman).

6. **Paket Kemitraan & Registrasi UMKM (Slide 3 & 7 Monetisasi)**
   - Featured Listing: Rp 50.000 / bulan.
   - Promosi Kilat: Rp 30.000 / event promosi.
   - Kampanye Bersama: Rp 100.000 / paket kampanye.
   - Form pendaftaran online terintegrasi langsung untuk pemilik warung.

7. **Ulasan Komunitas & Kenyang Meter**
   - Mahasiswa dapat mengirim ulasan riil dengan skor rasa (1-5 bintang) dan skor Kenyang Meter (1-5 porsi).

## 💻 Cara Menjalankan Website

1. Cukup buka file **`index.html`** langsung menggunakan web browser apa pun (Google Chrome, Microsoft Edge, Firefox).
2. Atau jalankan local server menggunakan Python:
   ```bash
   python -m http.server 8080
   ```
   Lalu buka di browser: `http://localhost:8080`
