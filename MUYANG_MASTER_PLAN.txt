BAGIAN 1 — GAMBARAN UMUM SISTEM
================================================================================

MUYANG adalah platform digital berbasis web yang menghubungkan:
  - Mahasiswa UNEJ (pencari kuliner hemat)
  - UMKM Kuliner Sekitar Kampus (penyedia makanan)
  - Admin MUYANG (pengelola platform)

Teknologi yang digunakan:
  Frontend   : HTML5, CSS3, JavaScript (Vanilla JS)
  Backend    : Node.js + Express.js  [RENCANA FASE 2]
  Database   : MongoDB (NoSQL) atau Firebase Realtime Database
  Auth       : JWT Token (backend) / localStorage (frontend demo)
  Hosting    : Vercel / Netlify (frontend) + Railway / Render (backend)
  Payment    : WhatsApp Manual Transfer [UTAMA] + Midtrans/Xendit [OPSIONAL]
  Maps       : Google Maps API (embed link koordinat)

Fase Pengembangan:
  FASE A : Frontend SPA berbasis localStorage (demo dosen) — dikerjakan sekarang
  FASE B : Backend Node.js + Database real                 — pengembangan lanjutan
  FASE C : Payment Gateway + Fitur Lanjutan                — opsional/masa depan

BAGIAN 5 — SISTEM REGISTER
================================================================================

------------------------------------------------------------------------
5.1 REGISTER MAHASISWA
------------------------------------------------------------------------
Trigger  : Klik [Daftar] di navbar → pilih "Saya Mahasiswa"
Metode   : Modal overlay (bukan halaman baru)

Form:
  - Nama Lengkap         (required)
  - NIM                  (required, 12 digit, harus unik)
  - Fakultas / Prodi     (required, dropdown)
  - Email                (optional, untuk notifikasi)
  - Password             (required, min 6 karakter)
  - Konfirmasi Password  (required, harus sama)

Validasi:
  - NIM format 12 digit angka
  - NIM belum terdaftar di localStorage
  - Password & konfirmasi cocok
  - Semua field required terisi

Hasil:
  - Data tersimpan ke localStorage['muyang_users_mahasiswa']
  - Session otomatis dibuat → langsung login
  - Redirect ke Landing Page dengan status login mahasiswa
  - Muncul toast: "Selamat datang, [Nama]! Akun berhasil dibuat."

------------------------------------------------------------------------
5.2 REGISTER UMKM (Multi-Step Form)
------------------------------------------------------------------------
Trigger  : Klik [Daftar Mitra UMKM] di navbar ATAU section Paket UMKM
Metode   : Modal overlay dengan progress bar 3 langkah

STEP 1 — Info Usaha:
  - Nama Warung / Usaha          (required)
  - Nama Pemilik                 (required)
  - Nomor WhatsApp Aktif         (required, format 08xx)
  - Kategori: [ Nasi | Mie | Minuman | Snack | Mix ]  (required)

STEP 2 — Lokasi:
  - Alamat Lengkap sekitar UNEJ  (required)
  - Patokan Lokasi               (required, contoh: "Belakang Gerbang UNEJ")
  - Link Google Maps warung      (optional, paste dari GMaps)
  - Jam Buka                     (optional, contoh: 07.00 – 21.00)

STEP 3 — Paket & Akun Login:
  - Pilih Paket:
    [ Featured Rp 50.000/bulan      ] ← direkomendasikan
    [ Promosi Kilat Rp 30.000/event ]
    [ Kampanye Bersama Rp 100.000   ]
  - Upload Foto Warung   (required, preview langsung)
  - Deskripsi Warung     (required, maks 200 karakter)
  - Email untuk login    (required, harus unik)
  - Password             (required, min 6 karakter)
  - Konfirmasi Password  (required)

Validasi:
  - Semua field required terisi
  - WhatsApp format valid
  - Email belum terdaftar
  - File foto maks 2MB
  - Password cocok

Hasil:
  - Data tersimpan ke localStorage['muyang_umkm_list'] dengan status: 'pending'
  - ID unik dibuat: "UMKM-[timestamp]"
  - Muncul halaman konfirmasi (bukan modal):
    "✅ Pendaftaran berhasil!
     ID Pendaftaran kamu: UMKM-001
     Kami akan mereview dalam 1x24 jam.
     Kamu akan dihubungi via WhatsApp: 08xxxxxxxx"
  - Tombol: "Pantau Status Pendaftaran → Login"

  - Butuh akun merchant terverifikasi (proses 1-3 hari)
  - Butuh backend real (tidak bisa localStorage)

================================================================================

  {
    id: 1,
    name: "Warung Bu Siti",
    lat: -8.1699,

    googleMapsUrl: "https://www.google.com/maps?q=-8.1699,113.7146",
    ...
  }

Perubahan di UI popup radar:
  Sebelum:
    [ Lihat Detail ]

  Sesudah:
    [ 🗺️ Buka di Google Maps → ]  ← link ke googleMapsUrl, target="_blank"
    [ 📋 Lihat Detail & Menu   ]

  Tambahkan baris:
    📍 Jl. Kalimantan No. 5 — Belakang Gerbang UNEJ

Koordinat yang perlu dicari untuk masing-masing warung seed data:
  - Gunakan Google Maps, klik titik lokasi warung → copy koordinat
  - Format: lat (angka negatif untuk selatan), lng (angka positif)
  - Contoh UNEJ: sekitar lat -8.1584 s/d -8.1750 | lng 113.7000 s/d 113.7300

BAGIAN 12 — ANTI-SPAM ULASAN
================================================================================

Mekanisme:
  - Mahasiswa HARUS login (NIM + password) sebelum bisa tulis ulasan
  - Setiap NIM hanya boleh 1 ulasan per warung
  - Jika sudah pernah ulasan → tombol berubah jadi "Sudah Diulas ✓" (disabled)

Implementasi localStorage:
  localStorage['muyang_reviewed'] = {
    "242410102001": [1, 3, 7],   // NIM ini sudah review warung ID 1, 3, 7
    "242410102002": [2, 5]
  }

  Cek sebelum submit:
  const reviewed = JSON.parse(localStorage.getItem('muyang_reviewed') || '{}')
  const nimReviewed = reviewed[session.nim] || []
  if (nimReviewed.includes(spotId)) {
    showError("Kamu sudah pernah memberi ulasan untuk warung ini!")
    return
  }

Tampilan ulasan di kartu warung:
  ★★★★★ "Porsinya banyak banget!" — Dimas S. (Mahasiswa UNEJ ✓)

  NIM ditampilkan parsial: 2424****2001 (sensor 4 digit tengah)

BAGIAN 13 — RENCANA BACKEND (FASE B)
================================================================================

------------------------------------------------------------------------
13.1 TEKNOLOGI STACK BACKEND
------------------------------------------------------------------------
  Runtime    : Node.js v20+
  Framework  : Express.js
  Database   : MongoDB Atlas (cloud, gratis tier)
               ATAU Firebase Realtime Database (lebih mudah setup)
  Auth       : JWT (JSON Web Token) + bcrypt (hash password)
  Upload     : Multer (file handling) + Cloudinary (image storage)
  Email      : Nodemailer + Gmail SMTP (notifikasi)
  Deploy     : Railway.app atau Render.com (gratis tier)
  CORS       : cors package untuk koneksi frontend-backend

------------------------------------------------------------------------
13.2 STRUKTUR ENDPOINT API (REST)
------------------------------------------------------------------------

  AUTH:
    POST   /api/auth/register/mahasiswa    → daftar akun mahasiswa
    POST   /api/auth/register/umkm         → daftar akun UMKM
    POST   /api/auth/login                 → login (semua role)
    POST   /api/auth/logout                → logout
    GET    /api/auth/me                    → cek session aktif

  MAHASISWA:
    GET    /api/mahasiswa/:nim             → profil mahasiswa
    PUT    /api/mahasiswa/:nim             → edit profil
    GET    /api/mahasiswa/:nim/bookmarks   → daftar bookmark
    POST   /api/mahasiswa/:nim/bookmarks   → tambah bookmark
    DELETE /api/mahasiswa/:nim/bookmarks/:spotId → hapus bookmark

  KULINER (publik):
    GET    /api/kuliner                    → semua data kuliner (+ filter)
    GET    /api/kuliner/:id               → detail kuliner
    GET    /api/kuliner/:id/reviews        → ulasan warung

  ULASAN:
    POST   /api/reviews                   → tulis ulasan baru
    DELETE /api/reviews/:id              → hapus ulasan (admin only)

  UMKM:
    POST   /api/umkm/register             → daftar UMKM baru
    GET    /api/umkm/:id                  → profil UMKM
    PUT    /api/umkm/:id                  → edit profil UMKM
    GET    /api/umkm/:id/menu             → daftar menu
    POST   /api/umkm/:id/menu            → tambah menu
    PUT    /api/umkm/:id/menu/:menuId    → edit menu
    DELETE /api/umkm/:id/menu/:menuId   → hapus menu
    POST   /api/umkm/:id/payment         → upload bukti bayar
    GET    /api/umkm/:id/status          → cek status UMKM

  ADMIN:
    GET    /api/admin/umkm                → semua UMKM per status
    PUT    /api/admin/umkm/:id/approve    → approve UMKM
    PUT    /api/admin/umkm/:id/reject     → tolak UMKM + alasan
    PUT    /api/admin/umkm/:id/verify-payment → konfirmasi bayar
    GET    /api/admin/reviews             → semua ulasan
    DELETE /api/admin/reviews/:id         → hapus ulasan
    GET    /api/admin/stats               → statistik platform
    GET    /api/admin/logs                → log aktivitas

13.4 NOTIFIKASI OTOMATIS (Nodemailer)
------------------------------------------------------------------------
  Trigger → Email dikirim ke:
  - UMKM daftar     → Email ke UMKM: "Pendaftaran diterima, menunggu review"
  - Admin approve   → Email ke UMKM: "Selamat! Silakan lakukan pembayaran"
  - Admin tolak     → Email ke UMKM: "Maaf, pendaftaran ditolak. Alasan: ..."
  - Bayar diverif   → Email ke UMKM: "Pembayaran terkonfirmasi! Dashboard aktif"
  - Paket hampir exp → Email ke UMKM: "Paket kamu berakhir 7 hari lagi"

13.5 INTEGRASI PAYMENT GATEWAY (Opsional - Fase C)
------------------------------------------------------------------------
  Provider   : Midtrans (by GoTo) — populer di Indonesia
  Sandbox    : Tersedia untuk testing tanpa uang sungguhan
  Metode bayar: QRIS, GoPay, OVO, Dana, Transfer Bank, Kartu Kredit

  Alur integrasi:
  1. Backend create transaction → dapat snap_token dari Midtrans
  2. Frontend tampilkan Midtrans Snap popup dengan snap_token
  3. User bayar di popup Midtrans
  4. Midtrans kirim webhook ke backend: status pembayaran
  5. Backend update status UMKM → active otomatis
  6. Email konfirmasi dikirim ke UMKM

  Kebutuhan:
  - Akun Midtrans merchant (daftar di dashboard.midtrans.com)
  - Server key & client key dari Midtrans
  - Endpoint webhook di backend (harus HTTPS → butuh domain/deploy)

  Alternatif lebih mudah: Xendit, Duitku, Tripay

BAGIAN 18 — CATATAN TEKNIS PENTING
================================================================================

  1. LOCALSTORAGE LIMIT:
     - Maksimal ~5-10 MB per domain
     - Foto (base64) bisa besar → compress sebelum simpan
     - Jika penuh → error → perlu handling graceful

  2. LOCALSTORAGE SCOPE:
     - Hanya berlaku di 1 browser, 1 device
     - Jika demo di laptop berbeda → seed data manual
     - Solusi: export/import JSON, atau gunakan Firebase

  3. KEAMANAN (Fase A - Demo):
     - Password disimpan plaintext (cukup untuk demo)
     - Di Fase B harus diganti bcrypt hash
     - Admin credential hardcoded (aman untuk demo, ganti di production)

  4. GAMBAR/FOTO:
     - Disimpan sebagai base64 string di localStorage
     - Compress ke maks 200KB sebelum simpan
     - Di Fase B → simpan ke Cloudinary, hanya URL yang disimpan di DB

  5. WHATSAPP LINK:
     - Format: https://wa.me/[nomor]?text=[pesan encoded]
     - Nomor harus format internasional tanpa + (62xxx)
     - Pesan harus di-encode dengan encodeURIComponent()
     - Bekerja di mobile (buka WA app) & desktop (buka WA Web)

  6. GOOGLE MAPS LINK:
     - Format sederhana: https://www.google.com/maps?q=[lat],[lng]
     - Atau dengan nama: https://www.google.com/maps/search/[nama+warung]
     - Target _blank agar tidak menutup halaman MUYANG
